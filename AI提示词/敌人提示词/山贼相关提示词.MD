以下是为三类山贼设计的 AI 动画提示词（按角色分类，涵盖通用 + 特有动作，突出像素风格与动作逻辑）：
一、普通山贼（持木棍，定位：弱小杂兵）
通用动作
待机：2D 像素风格，普通山贼待机动画。手持木棍自然垂落，身体轻微「左右摇晃」，头部缓慢「扫视四周」，姿态松散（肩膀微塌），循环播放，体现山贼的慵懒随性。
行走：2D 像素风格，普通山贼行走动画。双脚「蹒跚迈步」（步幅小、频率慢），木棍随步伐「小幅摆动」，上半身微颤，仿佛体力不足，突出 “杂鱼” 的迟钝感。
受伤：2D 像素风格，普通山贼受伤动画。被击中瞬间「后仰趔趄」，木棍「向前甩动」，身体「颤抖抽搐」（1-2 帧硬直），面部露出「痛苦皱眉」，反馈弱且短暂，符合低血量设定。
死亡：2D 像素风格，普通山贼死亡动画。重心失衡「侧倒 / 仰倒」，木棍「滑落身旁」，四肢「抽搐后摊开」，身体静止时呈 “无力瘫软” 姿态，强调脆弱。
特有动作（木棍近距离攻击）
攻击：2D 像素风格，普通山贼近战攻击动画。快速「挥棍横扫」（或向前戳刺），手臂发力带「轻微残影」，攻击后木棍「快速回收」至待机姿态，动作干脆（低帧速，突出像素打击感），体现 “朴实无华的杂兵攻击”。
二、精英山贼（持短刀 + 飞刀，定位：敏捷输出）
通用动作
待机：2D 像素风格，精英山贼待机动画。短刀「横握于腰侧」，身体「微蹲警觉」（重心放低），头部「快速扫视」（左右摆头），肌肉紧绷，展现 “随时突袭” 的机敏感。
行走：2D 像素风格，精英山贼行走动画。步伐「轻快迅捷」（步频快、步幅大），短刀「贴腿小幅摆动」，身体「前倾突进」，仿佛随时加速，突出灵活性。
受伤：2D 像素风格，精英山贼受伤动画。被击中后「跳步后退」，短刀「护胸防御」，面部「扭曲龇牙」（硬直时间短），快速恢复姿态，体现高敏捷的受击反馈。
死亡：2D 像素风格，精英山贼死亡动画。踉跄「倒地蜷缩」，短刀「脱手甩飞」，身体「抽搐收缩」，最终静止时呈 “瞬间失力” 状，强调爆发性死亡。
特有动作
投掷飞刀：2D 像素风格，精英山贼远程攻击动画。「抬手甩臂」（手腕发力），飞刀「快速射出」（附带「像素化轨迹光影」），投掷后手部「后摆收势」，动作流畅且迅速，突出 “远程消耗” 的战术性。
突进刀刺：2D 像素风格，精英山贼突进攻击动画。「低身快速前冲」（附带「残影暗示速度」），短刀「向前猛刺」（身体前倾贴地），攻击后「急停恢复站姿」，体现 “爆发突袭” 的压迫感。
三、山贼 BOSS（持巨锤，定位：重装坦克 + 范围压制）
通用动作
待机：2D 像素风格，山贼 BOSS 待机动画。巨锤「扛肩 / 拄地」，身体「大幅晃动」（幅度大、频率低），肌肉「紧绷鼓胀」，面部「威严怒容」（瞪眼 + 抿嘴），偶尔「闷哼发声」（可配像素化音效暗示），展现碾压级压迫感。
行走：2D 像素风格，山贼 BOSS 行走动画。步伐「沉重震地」（步幅大、落地有声），巨锤「拖地 / 小幅摆动」（附带「像素化地面震动特效」），身体「前倾压势」，突出 “移动即威慑” 的重量感。
受伤：2D 像素风格，山贼 BOSS 受伤动画。被击中后「剧烈后仰」，巨锤「短暂脱手抬起」，身体「摇晃震颤」（硬直时间长），面部「狰狞怒吼」（瞪眼 + 大张嘴巴），体现高血量的抗打击反馈。
死亡：2D 像素风格，山贼 BOSS 死亡动画。巨锤「砸地暴裂」（附带「像素块碎裂特效」），身体「栽倒压锤」，四肢「摊开瘫软」，最终静止时呈 “山崩式倒地”，强调震撼终结。
特有动作
跳跃砸击：2D 像素风格，BOSS 跳跃攻击动画。「高高跃起」（身体拉伸），双手「举锤过顶」，下落时「猛砸地面」（附带「大范围像素块飞溅」），砸击后锤「陷地半尺」，缓慢「回收姿势」，体现 “毁灭性打击” 的破坏力。
旋转锤击：2D 像素风格，BOSS 范围攻击动画。双手「握锤快速旋转」（360 度），锤风带「像素化残影」，攻击时身体「紧绷发力」，旋转后「收势站立」，展现 “全屏压制” 的威慑力。
狂暴 BUFF：2D 像素风格，BOSS 狂暴状态动画。肌肉「膨胀变红」（像素色调变化 + 轮廓加粗），攻击速度「加快」（动作帧缩短），移速「提升」（行走 / 攻击更迅猛），附带「红光闪烁特效」，持续期间动作「刚硬凶猛」（攻击幅度更大、收招更短），突出 “濒死爆发” 的威胁性。
设计逻辑：
从 动作幅度、速度、特效 区分层级（普通→精英→BOSS：迟缓→敏捷→厚重）；
特有动作紧扣定位（普通 “朴实近战”、精英 “远近结合”、BOSS“范围 + 爆发”）；
像素风格通过 “像素化残影 / 特效 / 光影” 强化复古质感，同时用 帧速、姿态 体现动作逻辑（如 BOSS 砸击用 “慢起快落” 突出重量）。
