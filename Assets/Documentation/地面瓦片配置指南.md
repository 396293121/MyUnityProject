# 战士部落地面瓦片配置指南

## 1. 图片导入设置

### 基础设置
- **Texture Type**: Sprite (2D and UI)
- **Sprite Mode**: Multiple
- **Pixels Per Unit**: 64
- **Filter Mode**: Point (no filter)
- **Compression**: None
- **Max Size**: 2048

### 高级设置
- **Generate Mip Maps**: 关闭
- **sRGB**: 开启
- **Alpha Source**: Input Texture Alpha
- **Alpha Is Transparency**: 开启

## 2. 瓦片切片方案

### 基础地面瓦片 (64x64像素)
```
[基础土地1] [基础土地2] [基础土地3]
[基础土地4] [基础土地5] [基础土地6]
[基础土地7] [基础土地8] [基础土地9]
```

### 边缘过渡瓦片
```
[左上角] [上边缘] [右上角] [特殊1]
[左边缘] [右边缘] [特殊2] [特殊3]
[左下角] [下边缘] [右下角] [特殊4]
```

### 装饰元素瓦片
```
[石头1] [石头2] [草丛1] [草丛2]
[石头3] [石头4] [草丛3] [草丛4]
```

## 3. 瓦片规则设置

### Rule Tile配置

#### 第一步：安装2D Tilemap Extras
1. 打开 `Window > Package Manager`
2. 点击左上角 `+` 按钮
3. 选择 `Add package by name...`
4. 输入：`com.unity.2d.tilemap.extras`
5. 点击 `Add` 完成安装

#### 第二步：创建Rule Tile资源
1. 在Project窗口右键点击
2. 选择 `Create > 2D > Tiles > Rule Tile`
3. 命名为 `地面Rule Tile`
4. 设置 `Default Sprite` 为基础地面瓦片

#### 第三步：配置基础边缘检测规则（简化16规则）
```
规则1 - 内部瓦片:     规则2 - 上边缘:
[✓] [✓] [✓]          [空] [空] [空]
[✓] [X] [✓]          [✓] [X] [✓]
[✓] [✓] [✓]          [✓] [✓] [✓]

规则3 - 下边缘:       规则4 - 左边缘:
[✓] [✓] [✓]          [空] [✓] [✓]
[✓] [X] [✓]          [空] [X] [✓]
[空] [空] [空]        [空] [✓] [✓]

规则5 - 右边缘:       规则6 - 左上角:
[✓] [✓] [空]         [空] [空] [空]
[✓] [X] [空]         [空] [X] [✓]
[✓] [✓] [空]         [空] [✓] [✓]

规则7 - 右上角:       规则8 - 左下角:
[空] [空] [空]        [空] [✓] [✓]
[✓] [X] [空]         [空] [X] [✓]
[✓] [✓] [空]         [空] [空] [空]

规则9 - 右下角:
[✓] [✓] [空]
[✓] [X] [空]
[空] [空] [空]
```

#### 第四步：配置随机变体（增加地形多样性）
1. 选择任意规则（建议选择内部瓦片规则）
2. 将 `Output` 类型改为 `Random`
3. 设置 `Size` 为 3-4
4. 添加变体精灵：
   - 变体1：基础地面瓦片（权重1.0）
   - 变体2：带小石头的地面（权重0.3）
   - 变体3：带草丛的地面（权重0.2）
   - 变体4：风化程度不同的地面（权重0.1）

#### 第五步：测试和应用
1. 将Rule Tile拖入Tile Palette
2. 在场景中测试绘制效果
3. 检查边缘是否正确连接
4. 验证随机变体是否生效

**详细配置参考**：`Assets/Art/Tile/瓦片素材/Rule Tile配置指南.md`

### 碰撞体设置
- 为地面瓦片添加Composite Collider 2D
- 设置Physics Material 2D (摩擦力: 0.4, 弹性: 0)

## 4. 层级设置

### Sorting Layer配置
- **Layer Name**: Ground
- **Order in Layer**: 0
- **Z Position**: 0

### Tilemap Renderer设置
- **Material**: Default-Diffuse
- **Sorting Layer**: Ground
- **Order in Layer**: 0

## 5. 性能优化

### 瓦片地图优化
- 启用Tilemap Collider 2D的"Used By Composite"
- 使用Composite Collider 2D减少碰撞体数量
- 设置合适的Chunk Size (默认32x32)

### 渲染优化
- 使用Sprite Atlas打包瓦片纹理
- 启用GPU Instancing (如果支持)
- 合理设置相机的Culling Mask

## 6. 与现有系统集成

### 相机边界系统
- 确保DynamicCameraBounds.cs能正确检测瓦片地图边界
- 在AutoFindTilemaps()中包含地面瓦片地图

### 视差背景系统
- 地面瓦片应排除在ParallaxBackground系统之外
- 设置正确的层级关系：背景 < 地面 < 角色 < 前景

## 7. 实际操作步骤

1. **导入图片**
   - 将地面图片放入 `Assets/Art/Tile/瓦片素材/` 文件夹
   - 按上述设置配置导入参数

2. **创建瓦片集**
   - 使用Sprite Editor进行切片
   - 创建对应的Tile Assets

3. **创建调色板**
   - Window > 2D > Tile Palette
   - 创建新的调色板文件
   - 将瓦片拖入调色板

4. **绘制地图**
   - 在场景中创建Tilemap对象
   - 使用Tile Palette进行地形绘制
   - 添加必要的碰撞体组件
