# 战士部落地面瓦片配置指南

## 1. 图片导入设置

### 基础设置
- **Texture Type**: Sprite (2D and UI)
- **Sprite Mode**: Multiple
- **Pixels Per Unit**: 64
- **Filter Mode**: Point (no filter)
- **Compression**: None
- **Max Size**: 2048

### 高级设置
- **Generate Mip Maps**: 关闭
- **sRGB**: 开启
- **Alpha Source**: Input Texture Alpha
- **Alpha Is Transparency**: 开启

## 2. 瓦片切片方案

### 基础地面瓦片 (64x64像素)
```
[基础土地1] [基础土地2] [基础土地3]
[基础土地4] [基础土地5] [基础土地6]
[基础土地7] [基础土地8] [基础土地9]
```

### 边缘过渡瓦片
```
[左上角] [上边缘] [右上角] [特殊1]
[左边缘] [右边缘] [特殊2] [特殊3]
[左下角] [下边缘] [右下角] [特殊4]
```

### 装饰元素瓦片
```
[石头1] [石头2] [草丛1] [草丛2]
[石头3] [石头4] [草丛3] [草丛4]
```

## 3. 瓦片规则设置

### Rule Tile配置
- 使用Unity 2D Tilemap Extras中的Rule Tile
- 设置自动边缘检测规则
- 配置随机变体以增加地形多样性

### 碰撞体设置
- 为地面瓦片添加Composite Collider 2D
- 设置Physics Material 2D (摩擦力: 0.4, 弹性: 0)

## 4. 层级设置

### Sorting Layer配置
- **Layer Name**: Ground
- **Order in Layer**: 0
- **Z Position**: 0

### Tilemap Renderer设置
- **Material**: Default-Diffuse
- **Sorting Layer**: Ground
- **Order in Layer**: 0

## 5. 性能优化

### 瓦片地图优化
- 启用Tilemap Collider 2D的"Used By Composite"
- 使用Composite Collider 2D减少碰撞体数量
- 设置合适的Chunk Size (默认32x32)

### 渲染优化
- 使用Sprite Atlas打包瓦片纹理
- 启用GPU Instancing (如果支持)
- 合理设置相机的Culling Mask

## 6. 与现有系统集成

### 相机边界系统
- 确保DynamicCameraBounds.cs能正确检测瓦片地图边界
- 在AutoFindTilemaps()中包含地面瓦片地图

### 视差背景系统
- 地面瓦片应排除在ParallaxBackground系统之外
- 设置正确的层级关系：背景 < 地面 < 角色 < 前景

## 7. 实际操作步骤

1. **导入图片**
   - 将地面图片放入 `Assets/Art/Tile/瓦片素材/` 文件夹
   - 按上述设置配置导入参数

2. **创建瓦片集**
   - 使用Sprite Editor进行切片
   - 创建对应的Tile Assets

3. **创建调色板**
   - Window > 2D > Tile Palette
   - 创建新的调色板文件
   - 将瓦片拖入调色板

4. **绘制地图**
   - 在场景中创建Tilemap对象
   - 使用Tile Palette进行地形绘制
   - 添加必要的碰撞体组件
