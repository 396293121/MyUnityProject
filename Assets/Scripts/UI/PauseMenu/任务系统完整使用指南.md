# 任务系统完整使用指南

## 概述

本任务系统是一个完整的、可扩展的任务管理解决方案，支持多种任务类型、进度追踪、奖励系统和UI集成。

## 系统架构

```
任务系统架构
├── QuestManager (任务管理核心)
│   ├── QuestData (任务数据)
│   ├── QuestObjective (任务目标)
│   └── QuestReward (任务奖励)
├── EnemyKillTracker (击杀追踪器)
├── QuestPanel (任务面板)
└── DialogueManager (对话系统集成)
```

## 快速开始

### 1. 基础设置

在场景中创建一个空的GameObject，添加`QuestManager`组件：

```csharp
// QuestManager 会自动初始化并创建必要的组件
// 包括 EnemyKillTracker 等
GameObject questManagerObj = new GameObject("QuestManager");
QuestManager questManager = questManagerObj.AddComponent<QuestManager>();
```

### 2. 创建任务配置

#### 方法一：使用ScriptableObject（推荐）

1. 在Project窗口右键 → Create → Quest → Kill Quest
2. 配置任务参数：
   - 任务ID：`kill_wild_boar_001`
   - 任务名称：`清理野猪`
   - 目标敌人类型：`WildBoar`
   - 击杀数量：`10`
   - 奖励：经验值100，金币50

#### 方法二：代码创建

```csharp
// 创建击杀野猪任务
var killBoarQuest = ScriptableObject.CreateInstance<KillWildBoarQuestData>();
killBoarQuest.targetEnemyType = "WildBoar";
killBoarQuest.requiredKillCount = 10;
killBoarQuest.experienceReward = 100;
killBoarQuest.goldReward = 50;
killBoarQuest.InitializeQuest();

// 添加到任务系统
QuestManager.Instance.AddQuestToDatabase(killBoarQuest);
```

### 3. 启动任务

```csharp
// 通过任务ID启动
QuestManager.Instance.StartQuest("kill_wild_boar_001");

// 或通过任务数据启动
QuestManager.Instance.StartQuest(killBoarQuest);
```

### 4. 追踪进度

任务进度会自动更新，当敌人死亡时：

```csharp
// Enemy.cs中的Die方法会自动触发
OnDeath?.Invoke(this);

// EnemyKillTracker会自动处理
// QuestManager会自动更新相关任务进度
```

## 详细功能说明

### 任务类型

#### 1. 击杀任务 (KillQuest)
- **用途**：击杀指定数量的特定敌人
- **配置**：目标敌人类型、击杀数量
- **示例**：击杀10只野猪、击杀5只哥布林

#### 2. 收集任务 (CollectQuest)
- **用途**：收集指定数量的物品
- **配置**：目标物品类型、收集数量
- **示例**：收集10个苹果、收集5个草药

#### 3. 主线任务 (MainQuest)
- **用途**：推进游戏主要剧情
- **特点**：不能放弃、优先级高

#### 4. 支线任务 (SideQuest)
- **用途**：额外的游戏内容
- **特点**：可以放弃、可选完成

### 任务状态

- **NotStarted**：未开始
- **Active**：进行中
- **Completed**：已完成
- **Failed**：已失败
- **Abandoned**：已放弃

### 奖励系统

支持多种奖励类型：

```csharp
// 经验值奖励
new QuestReward { rewardType = RewardType.Experience, experienceAmount = 100 }

// 金币奖励
new QuestReward { rewardType = RewardType.Gold, goldAmount = 50 }

// 物品奖励
new QuestReward { 
    rewardType = RewardType.Item, 
    items = new List<ItemReward> { 
        new ItemReward { itemId = "sword_001", quantity = 1 }
    }
}
```

### 对话系统集成

#### NPC任务分发

```csharp

public List<QuestData> availableQuests;
public NPCType npcType = NPCType.QuestGiver;

// 给予任务
npcController.GiveQuest("kill_wild_boar_001");
```

#### Fungus对话命令

在Fungus对话中使用自定义命令：

```
# 给予任务
GiveQuest questId="kill_wild_boar_001"

# 检查任务状态
CheckQuestStatus questId="kill_wild_boar_001" targetBlock="QuestCompleted"

# 完成任务
CompleteQuest questId="kill_wild_boar_001"
```

## 扩展开发

### 创建新的任务类型

1. 继承`QuestData`基类：

```csharp
[CreateAssetMenu(fileName = "NewQuestType", menuName = "Quest/New Quest Type")]
public class NewQuestTypeData : QuestData
{
    [Header("新任务类型配置")]
    public string customParameter;
    
    public override void InitializeQuest()
    {
        base.InitializeQuest();
        // 自定义初始化逻辑
    }
    
    public override bool ValidateQuest()
    {
        // 自定义验证逻辑
        return base.ValidateQuest();
    }
}
```

2. 在`QuestType`枚举中添加新类型
3. 在`QuestManager`中添加处理逻辑

### 添加新的奖励类型

1. 在`RewardType`枚举中添加新类型
2. 在`QuestReward`类中添加相关字段
3. 在`QuestManager.GiveQuestReward`中添加处理逻辑

### 自定义UI组件

1. 继承或修改现有UI组件
2. 实现自定义显示逻辑
3. 注册事件监听

## 最佳实践

### 1. 任务设计原则

- **清晰的目标**：任务目标要明确、易懂
- **合理的奖励**：奖励要与任务难度匹配
- **渐进式难度**：任务难度要循序渐进
- **多样化类型**：提供不同类型的任务体验

### 2. 性能优化

- **延迟加载**：只在需要时加载任务数据
- **事件驱动**：使用事件系统减少轮询
- **对象池**：复用UI组件减少GC
- **批量更新**：批量处理UI更新

### 3. 数据管理

- **版本控制**：为任务数据添加版本号
- **备份机制**：定期备份任务进度
- **数据验证**：在加载时验证数据完整性
- **迁移策略**：为数据结构变更准备迁移方案

## 故障排除

### 常见问题

1. **任务进度不更新**
   - 检查EnemyKillTracker是否正确初始化
   - 确认Enemy.OnDeath事件是否正确触发
   - 验证任务ID是否匹配

2. **UI显示异常**
   - 检查UI组件引用是否正确
   - 确认事件监听是否正确注册
   - 验证数据绑定是否正确

3. **对话集成问题**
   - 检查Fungus命令是否正确配置
   - 确认NPCController设置是否正确
   - 验证对话流程是否正确
