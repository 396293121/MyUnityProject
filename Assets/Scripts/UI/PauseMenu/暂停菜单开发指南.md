# 暂停菜单系统开发指南

## 概述

本文档详细说明如何在Unity中使用生成的脚本配合Unity UI系统开发暂停菜单、角色菜单和任务菜单。

## 系统架构

### 核心组件
1. **PauseMenuManager** - 暂停菜单管理器，负责整体逻辑
2. **CharacterPanel** - 角色面板，显示角色属性
3. **QuestPanel** - 任务面板，显示任务信息
4. **QuestManager** - 任务管理器，管理任务逻辑
5. **QuestData** - 任务数据结构

### 设计特点
- **高扩展性**: 使用接口和模块化设计，易于添加新功能
- **低耦合**: 各模块独立，通过事件和接口通信
- **易于维护**: 清晰的代码结构和完整的注释

## Unity UI 设置步骤

### 第一步：创建基础UI结构

#### 1.1 创建Canvas
```
1. 在Hierarchy中右键 -> UI -> Canvas
2. 设置Canvas Scaler为Scale With Screen Size
3. Reference Resolution设置为1920x1080
4. Screen Match Mode设置为Match Width Or Height，Match值为0.5
```

### 第七步：集成现有系统

#### 7.1 与UIManager集成
```csharp
// 在UIManager中注册暂停菜单
public void OnGamePause()
{
    var pauseMenuManager = FindObjectOfType<PauseMenuManager>();
    if (pauseMenuManager != null)
    {
        pauseMenuManager.OpenPauseMenu();
    }
}
```

#### 7.2 与InputManager集成
```csharp
// 在InputManager中处理ESC键
private void HandlePauseInput()
{
    if (Input.GetKeyDown(KeyCode.Escape))
    {
        var pauseMenuManager = FindObjectOfType<PauseMenuManager>();
        if (pauseMenuManager != null)
        {
            pauseMenuManager.TogglePauseMenu();
        }
    }
}
```

#### 7.3 与GameManager集成
```csharp
// 确保GameManager有暂停和恢复方法
public void PauseGame()
{
    Time.timeScale = 0f;
    currentState = GameState.Paused;
}

public void ResumeGame()
{
    Time.timeScale = 1f;
    currentState = GameState.Playing;
}
```

### 常见问题解决

#### 问题1: 面板不显示
```
解决方案:
1. 检查Canvas设置
2. 确认面板的Active状态
3. 检查脚本引用是否正确
```

#### 问题2: 按钮无响应
```
解决方案:
1. 检查Button组件的Interactable属性
2. 确认事件绑定正确
3. 检查Canvas的GraphicRaycaster组件
```

#### 问题3: 数据不更新
```
解决方案:
1. 确认数据源正确
2. 检查事件订阅
3. 手动调用RefreshContent()
```

## 扩展功能

### 添加新标签页
1. 创建新的面板脚本，实现IPauseMenuContent接口
2. 在PauseMenuManager的tabs列表中添加新标签页配置
3. 注册到PauseMenuManager

### 添加新任务类型
1. 在QuestType枚举中添加新类型
2. 在QuestPanel中添加对应的分类按钮
3. 更新GetQuestTypeText方法

### 添加动画效果
1. 使用DOTween或Unity Animation
2. 在ShowContent和HideContent中添加动画
3. 为按钮添加点击动画

## 性能优化建议

1. **对象池**: 对于频繁创建销毁的UI元素使用对象池
2. **延迟加载**: 只在需要时创建和更新UI
3. **批量更新**: 避免频繁的单个UI更新
4. **内存管理**: 及时清理不需要的UI引用

- **事件驱动**: 使用事件系统实现松耦合
