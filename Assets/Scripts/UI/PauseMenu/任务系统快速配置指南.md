# 任务系统快速配置指南

## 系统概述

任务系统包含以下核心组件：
- `QuestManager` - 任务管理器（自动初始化）
- `EnemyKillTracker` - 敌人击杀追踪器（自动创建）
- `QuestData` - 任务数据配置
- `QuestObjective` - 任务目标系统
- `QuestPanel` - 任务面板（暂停菜单标签页）

## 快速开始

### 1. 添加任务系统管理器

在场景中创建一个空的GameObject，命名为"QuestManager"，添加以下组件：
- `QuestManager` - 任务管理器（自动初始化）

## 第二步：配置NPC

### 1. 设置任务给予者
```csharp
// 在NPC脚本中设置
public NPCType npcType = NPCType.QuestGiver;
```

## 第四步：创建任务配置

### 1. 创建任务数据
1. 右键点击项目窗口
2. 选择 `Create > Quest System > Quest Data`
3. 配置任务基本信息

### 2. 击杀任务配置示例
```yaml
questId: "kill_wild_boar_001"
questName: "清理野猪"
description: "村庄附近的野猪太多了，请帮忙清理一些。"
questType: KillQuest
objectives:
  - description: "击杀野猪 {current}/{target}"
    objectiveType: 0  # KillEnemy
    targetId: "WildBoar"
    currentProgress: 0
    targetProgress: 10
    parameters:
      minEnemyLevel: 1
      maxEnemyLevel: 5
```

### 3. 收集任务配置示例
```yaml
questId: "collect_herbs_001"
questName: "采集草药"
description: "为药剂师收集一些草药。"
questType: CollectQuest
objectives:
  - description: "收集草药 {current}/{target}"
    objectiveType: 1  # CollectItem
    targetId: "Herb"
    currentProgress: 0
    targetProgress: 5
    parameters:
      itemQuality: "Common"
      location: "Forest"
```

### 4. 多目标任务配置示例

## 游戏流程示例

### 1. 基本流程
1. 玩家与NPC对话
2. NPC给予任务（通过Fungus对话系统）
3. 玩家执行任务（击杀敌人、收集物品等）
4. 系统自动更新任务进度
5. 任务完成后返回NPC
6. 获得奖励

### 2. 代码示例
```csharp
// NPC对话脚本示例
public class QuestDialogue : MonoBehaviour
{
    public void GiveQuest(string questId)
    {
        if (QuestManager.Instance.StartQuest(questId))
        {
            Debug.Log($"任务 {questId} 已接受");
        }
    }
    
    public bool IsQuestCompleted(string questId)
    {
        var quest = QuestManager.Instance.GetQuestById(questId);
        return quest != null && quest.questStatus == QuestStatus.Completed;
    }
    
    public void CompleteQuest(string questId)
    {
        QuestManager.Instance.CompleteQuest(questId);
    }
}
```

## 故障排除

### 常见问题

1. **任务无法启动**
   - 检查任务ID是否正确
   - 确认任务已添加到QuestManager的数据库中
   - 检查玩家等级是否满足要求

2. **击杀进度不更新**
   - 确认敌人的enemyType与任务目标ID匹配
   - 检查Enemy的OnDeath事件是否正确触发
   - 确认EnemyKillTracker已正确初始化

3. **UI不显示**
   - 检查QuestPanel是否正确配置
   - 确认UI预制件已正确设置
   - 检查Canvas和UI组件的激活状态

## 🔧 常见问题解决

### Q: 任务无法启动？
**A:** 检查以下项目：
- QuestManager是否正确初始化
- 任务配置文件是否存在于正确路径
- NPC的availableQuests列表是否包含正确的任务ID

### Q: 击杀不计数？
**A:** 检查以下项目：
- Enemy组件的enemyType是否正确设置
- EnemyKillTracker是否正确初始化
- Enemy的OnDeath事件是否正确触发

### Q: 任务指示器不显示？
**A:** 检查以下项目：
- questIndicator和questCompleteIndicator是否正确赋值
- NPC的npcType是否设置为QuestGiver
- UpdateQuestIndicators方法是否被正确调用

### Q: 对话命令不工作？
**A:** 检查以下项目：
- QuestFungusCommands.cs是否正确添加到项目
- Fungus命令是否正确配置
- 任务ID是否与配置文件中的ID匹配
