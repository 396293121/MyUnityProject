## 🏗️ 系统架构

### 核心组件层次结构：

```
QuestSystemManager (预制体)
├── QuestManager               # 任务管理核心 (自动初始化)
└── EnemyKillTracker          # 击杀追踪器 (自动创建)

NPCController                  # NPC任务发布
├── 任务指示器管理
├── 任务状态检查
└── 与对话系统集成

QuestPanel                   # 任务面板（暂停菜单标签页）
├── 任务列表显示
├── 任务详情显示
└── 进度更新

DialogueManager + Fungus      # 对话系统集成
├── GiveQuestCommand
├── CompleteQuestCommand
├── CheckQuestStatusCommand
└── CheckQuestCompletableCommand
```

## 🔄 数据流程

### 1. 系统初始化流程：
```
游戏启动 → QuestManager (单例自动初始化) → EnemyKillTracker (自动创建) → 预加载任务
```

### 2. 任务启动流程：
```
玩家与NPC对话 → Fungus GiveQuestCommand → QuestManager.StartQuest → 任务状态更新 → UI刷新
```

### 3. 进度更新流程：
```
敌人死亡 → Enemy.OnDeath → EnemyKillTracker → QuestManager → 任务进度更新 → UI刷新
```

### 4. 任务完成流程：
```
目标达成 → 自动检测 → 状态变更为Completed → NPC指示器更新 → 玩家交任务 → 奖励发放
```

## 🎯 关键设计模式

### 1. 单例模式 (Singleton)
- `QuestManager.Instance`
- `EnemyKillTracker.Instance`
- `DialogueManager.Instance`

### 2. 观察者模式 (Observer)
- 任务事件系统：`OnQuestStarted`, `OnQuestCompleted`, `OnQuestProgressUpdated`
- 敌人击杀事件：`OnEnemyKilled`

### 3. 策略模式 (Strategy)
- 不同任务类型的处理：`QuestData` 基类 + 具体实现类

### 4. 工厂模式 (Factory)
- ScriptableObject 任务配置文件的加载和实例化

## 📈 扩展指南

### 添加新任务类型：
1. 继承 `QuestData` 基类
2. 实现 `UpdateProgress()` 和 `GetProgressPercentage()` 方法
3. 在 `QuestManager` 中添加对应的事件处理
4. 创建对应的ScriptableObject配置

### 添加新UI功能：
1. 扩展 `QuestPanel` 类
2. 修改 `QuestItemUI` 显示逻辑
3. 添加新的UI面板和交互

### 集成其他系统：
1. 通过事件系统与其他游戏系统通信
2. 使用 `QuestManager` 的公共API进行集成
3. 遵循现有的架构模式
