# Rule Tile 通用配置模板

## 快速配置流程

### 1. 安装依赖
```
Package Manager > Add package by name > com.unity.2d.tilemap.extras
```

### 2. 创建Rule Tile
```
Create > 2D > Tiles > Rule Tile
```

### 4. 随机变体配置

#### 标准配置（适用所有风格）
```
内部瓦片规则 > Output: Random
├── 变体1: 基础瓦片 (权重: 1.0)
├── 变体2: 装饰变体1 (权重: 0.3)
├── 变体3: 装饰变体2 (权重: 0.2)
└── 变体4: 特殊变体 (权重: 0.1)
```

#### 权重分配原则
- 基础瓦片：1.0（主要外观）
- 轻微变化：0.3-0.5（小装饰）
- 明显变化：0.1-0.2（特殊元素）

### 6. 常见问题解决

#### 边缘不连接
```
检查项：
1. 规则配置是否正确
2. Sprite切片是否精确
3. Pixels Per Unit是否一致
```

#### 随机变体不生效
```
检查项：
1. Output类型是否设为Random
2. 变体Sprite是否正确分配
3. 权重设置是否合理
```

#### 性能问题
```
优化方案：
1. 减少不必要的规则
2. 合并相似的变体
3. 使用Sprite Atlas
```

### 7. 扩展应用

#### 多层地形
```
地面层：基础Rule Tile
装饰层：透明背景的装饰Rule Tile
细节层：小装饰元素
```

#### 季节变化
```
春季Rule Tile：绿色调
夏季Rule Tile：明亮色调
秋季Rule Tile：暖色调
冬季Rule Tile：冷色调
```

#### 不同生物群落
```
森林：绿色地面 + 落叶装饰
沙漠：黄色地面 + 沙丘纹理
雪地：白色地面 + 雪花装饰
岩石：灰色地面 + 石块装饰
```
