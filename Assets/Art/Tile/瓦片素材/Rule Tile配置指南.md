# Unity Rule Tile 完整配置指南

## 1. 安装 2D Tilemap Extras

### 方法一：通过Package Manager安装
1. 打开 `Window > Package Manager`
2. 点击左上角的 `+` 按钮
3. 选择 `Add package by name...`
4. 输入：`com.unity.2d.tilemap.extras`
5. 点击 `Add` 完成安装

### 方法二：手动添加到manifest.json
在 `Packages/manifest.json` 的 dependencies 中添加：
```json
"com.unity.2d.tilemap.extras": "4.0.2"
```

## 2. 创建基础Rule Tile

### 2.1 创建Rule Tile资源
1. 在Project窗口中右键点击
2. 选择 `Create > 2D > Tiles > Rule Tile`
3. 命名为 `地面Rule Tile`

### 2.2 基础设置
```
Default Sprite: 选择基础地面瓦片
Default GameObject: 留空
Default Collider: None
```

## 3. 自动边缘检测规则配置

### 3.1 标准47规则模板（推荐）
这是最通用的边缘检测规则，适用于所有地形类型：

```
规则数量: 47个
包含: 内角、外角、边缘、孤立瓦片等所有情况
```

### 3.2 简化16规则模板（快速配置）
适合快速原型和简单地形：

## 4. 配置随机变体

### 4.1 启用随机输出
在Rule Tile Inspector中：
1. 找到需要添加变体的规则
2. 将 `Output` 类型改为 `Random`
3. 设置 `Size` 为变体数量（建议2-4个）

### 4.2 添加变体精灵
```
变体1: 基础地面瓦片
变体2: 带小石头的地面瓦片
变体3: 带草丛的地面瓦片
变体4: 风化程度不同的地面瓦片
```

### 4.3 权重设置
```
变体1权重: 1.0 (最常见)
变体2权重: 0.3 (偶尔出现)
变体3权重: 0.2 (较少出现)
变体4权重: 0.1 (稀有)
```

## 5. 通用Rule Tile模板

### 5.1 创建可复用的模板
```csharp
// 保存路径: Assets/Art/Tile/Templates/

- 特殊地形Rule Tile模板.asset
```

### 5.2 模板配置参数
```
基础参数:
- Tiling Rules: 16个基础规则
- Default Sprite: 基础瓦片
- Random Output: 启用，3-4个变体

高级参数:
- Neighbor Type: This
- Check Transform: None
- Output Transform: Fixed
```

## 6. 实际操作流程

### 6.1 准备瓦片精灵
```
所需精灵数量:
- 基础瓦片: 1个
- 边缘瓦片: 4个（上下左右）
- 角落瓦片: 4个（四个角）
- 变体瓦片: 3-4个（可选）
```

### 6.2 快速配置步骤
1. **创建Rule Tile资源**
   - 右键 > Create > 2D > Tiles > Rule Tile

2. **设置默认精灵**
   - 拖拽基础地面瓦片到 Default Sprite

3. **添加规则**
   - 点击 `+` 添加新规则
   - 设置邻居检查模式
   - 指定输出精灵

4. **配置随机变体**
   - 选择规则，改Output为Random
   - 添加变体精灵

5. **测试和调整**
   - 在Tile Palette中测试绘制效果
   - 根据需要调整规则优先级

## 7. 性能优化建议

### 7.1 规则数量优化
```
推荐配置:
- 简单地形: 16个规则
- 复杂地形: 47个规则
- 避免超过100个规则
```

### 7.2 变体数量控制
```
建议配置:
- 基础瓦片: 2-3个变体
- 边缘瓦片: 1-2个变体
- 装饰瓦片: 3-4个变体
```

### 7.3 纹理优化
```
- 使用Sprite Atlas打包所有瓦片
- 保持一致的像素密度
- 避免过大的纹理尺寸
```

## 8. 常见问题解决

### 8.1 边缘不匹配
```
解决方案:
1. 检查邻居检查模式设置
2. 确认规则优先级顺序
3. 验证精灵的对齐方式
```

### 8.2 随机变体不生效
```
解决方案:
1. 确认Output类型为Random
2. 检查变体精灵是否正确设置
3. 重新绘制瓦片以刷新随机结果
```

### 8.3 性能问题
```
解决方案:
1. 减少不必要的规则
2. 使用Composite Collider 2D
3. 启用瓦片地图的静态批处理
```
