# 战士部落地面 Rule Tile 配置示例

## 实际操作步骤

### 第一步：准备工作
1. 确保已安装 `2D Tilemap Extras` 包
2. 准备战士部落地面瓦片素材（64x64px）

### 第二步：创建Rule Tile
1. 在 `Assets/Art/Tile/瓦片素材/` 文件夹右键
2. 选择 `Create > 2D > Tiles > Rule Tile`
3. 命名为 `战士部落地面_Rule Tile`

### 第三步：基础配置
```
Default Sprite: 战士部落基础地面瓦片
Default GameObject: 无
Default Collider: 无
```

### 第五步：测试配置
1. 将Rule Tile拖入Tile Palette
2. 在测试场景中绘制地面
3. 检查边缘连接效果
4. 验证随机变体是否正常

### 第六步：优化调整
```
如果边缘不连接：
- 检查规则配置
- 确认瓦片切片精度
- 验证Pixels Per Unit设置

如果随机变体太频繁：
- 降低装饰变体权重
- 增加基础瓦片权重

如果性能有问题：
- 减少随机变体数量
- 简化规则配置
```

### 第七步：集成到项目
1. 确保地面瓦片地图在 `DynamicCameraBounds.cs` 的 `tilemaps` 数组中
2. 测试相机边界自动计算
3. 验证碰撞检测正常工作
